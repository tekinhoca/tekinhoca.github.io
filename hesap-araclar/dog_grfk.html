Temel Kavramlar
Genel Form: ax + by + c = 0
a, b, c gerçel sayılardır.
a ve b aynı anda sıfır olamaz.
Açık Form: y = mx + n
m = −a/b   (eğim)
n = −c/b   (y-kesim noktası)
Eğim (m): Doğrunun x eksenine göre yükselme/ilerleme oranı.
m > 0 → artan grafik
m < 0 → azalan grafik
m = 0 → x eksenine paraleldir
⚠️ x eksenine dik doğruların eğimi tanımsızdır.
Eksen Kesim Noktaları:
x = 0 → y eksenini keser: (0, n)
y = 0 → x eksenini keser: (−n/m, 0)
İki Doğrunun Kesişimi:
İki denklem sistemi çözülerek bulunur.
Paralelse kesişmez (m₁ = m₂, n₁ ≠ n₂)
Çakışıksa sonsuz çözüm (m₁ = m₂, n₁ = n₂)
