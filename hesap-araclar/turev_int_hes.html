Türev Tanımı
\(f'(x) = \lim_{h \to 0} \dfrac{f(x+h)-f(x)}{h}\)

Temel Kurallar

Sabit terimin türevi:
\((c)' = 0\)
Üslü ifadenin türevi:
\((x^n)' = nx^{n-1}\)
Çarpımın türevi:
\((f \cdot g)' = f'g + fg'\)
Bölümün türevi:
\(\left(\dfrac{f}{g}\right)' = \dfrac{f'g - fg'}{g^2}\)
Bileşke fonkiyonun türevi:
\((f(g))' = f'(g)\cdot g'\)

Türev Tablosu

\((\sin x)' = \cos x\)
\((\cos x)' = -\sin x\)
\((\tan x)' = \dfrac{1}{\cos^2 x}\)
\((e^x)' = e^x\)
\((\ln x)' = \dfrac{1}{x}\)
\((a^x)' = a^x \ln a\)
İntegral Tanımı
\(F'(x) = f(x)\) olmak üzere
Belirsiz İntegral:
\(\int f(x)\,dx = F(x) + c\)
Belirli İntegral:
\(\int_a^b f(x)\,dx = F(b) - F(a)\)

Temel İntegraller

\(\int x^n dx = \dfrac{x^{n+1}}{n+1} + c\)
\(\int \sin x\,dx = -\cos x + c\)
\(\int \cos x\,dx = \sin x + c\)
\(\int e^x dx = e^x + c\)
\(\int \dfrac{1}{x} dx = \ln|x| + c\)
